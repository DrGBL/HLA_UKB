# UKB WES HLA calling

This contains the code to reproduce results in the paper (https://www.nature.com/articles/s42003-023-05496-5). It is split in 8 sections for ease. Users will need to adapt some of the code for their local clusters (most importantly the path to different files and folders), especially for analyses of the HLA alleles calling results (e.g. association studies).

Unfortunately, while we gave back all of the generated data to the UK Biobank, to our understanding it has not been made available to researchers yet (as of 2026-02-19). We encourage any interested researchers to contact the UK Biobank directly to let them know that this data would be useful. We are also happy to collaborate directly with you if you have specific research questions that this data can be used for (please contact the corresponding author directly via email).
